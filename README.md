Cronos Pomodoro ⏱️
O Cronos Pomodoro é um projeto de estudos desenvolvido com React e TypeScript durante um curso da Udemy. A proposta é construir um temporizador inspirado na técnica Pomodoro, que organiza as atividades em períodos de concentração intercalados com pausas para descanso.

Além de colocar a técnica em prática, este repositório registra minha evolução no desenvolvimento de interfaces, desde a criação e configuração de um projeto até a implementação de funcionalidades com React.
🎯 Objetivo
Desenvolver uma aplicação simples e intuitiva para ajudar na organização do tempo de estudo ou trabalho, praticando os fundamentos de React e TypeScript e ganhando autonomia no desenvolvimento de projetos.
🛠️ Tecnologias
- React
- TypeScript
- Vite
- HTML e CSS
📚 Aprendizados
Durante o desenvolvimento, pretendo praticar:
- Criação e configuração de projetos com Vite;
- Organização de arquivos e componentes React;
- Utilização de propriedades, estados e eventos;
- Construção da interface e implementação do temporizador;
- Uso do Git e GitHub para acompanhar a evolução do código.
🚧 Status
Em desenvolvimento. Projeto realizado como exercício prático de um curso da Udemy. As funcionalidades e a documentação serão atualizadas conforme o avanço das aulas.
